1. count(x)
    Purpose: Returns the number of times a given value x appears in the tuple.
    Example:
    my_tuple = (1, 2, 3, 2, 4, 2)
    print(my_tuple.count(2))  # Output: 3

2. index(x)
    Purpose: Returns the index of the first occurrence of the given value x in the tuple. Raises a ValueError if the value is not found.
    Example:
    my_tuple = ('apple', 'banana', 'cherry')
    print(my_tuple.index('banana'))  # Output: 1

3. len(my_tuple)
    Purpose: Returns the length (number of elements) of the tuple.
    Example:
    my_tuple = (1, 2, 3, 4, 5)
    print(len(my_tuple))  # Output: 5

4. max(my_tuple)
    Purpose: Returns the largest element in the tuple. If the tuple contains multiple data types, it will raise a TypeError.
    Example:
    my_tuple = (10, 2, 8, 5)
    print(max(my_tuple))  # Output: 10

5. min(my_tuple)
    Purpose: Returns the smallest element in the tuple. If the tuple contains multiple data types, it will raise a TypeError.
    Example:
    my_tuple = (10, 2, 8, 5)
    print(min(my_tuple))  # Output: 2

6. sum(my_tuple)
    Purpose: Returns the sum of all elements in the tuple. If the tuple contains non-numeric elements, it will raise a TypeError.
    Example:
    my_tuple = (1, 2, 3, 4)
    print(sum(my_tuple))  # Output: 10

Important Notes:
    You can use these methods directly on a tuple, but they are not "methods" belonging to the tuple object itself. They are built-in functions in Python.
    The immutability of tuples makes them more secure and predictable, especially when working with large datasets or in multi-threaded environments.
    Most operations that would modify a tuple (e.g., appending or removing elements) are not possible. Instead, you would need to create a new tuple.
