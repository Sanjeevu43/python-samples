
Core Prompt Roles:
1 system:
   Purpose: Sets the stage, provides high-level instructions, defines the AI's persona, rules, constraints,
   or context before the main conversation starts. It acts as a guiding directive for the entire 
   interaction.

   Placement: Typically the very first message in the list (if used). There's usually only one system 
   message per conversation.

   Example: "You are a helpful assistant that translates English to French." or "You are Shakespeare. 
   Respond in iambic pentameter."

2 user:
  Purpose: Represents the input provided by the human user. This is what the user actually types or asks.
  Placement: Appears whenever the human provides input. Usually alternates with the assistant role.
  Example: "Translate 'hello world' to French." or "Tell me a joke."
  
3 assistant (or sometimes model):
  Purpose: Represents the response generated by the AI model. This includes past responses in the 
  conversation history and is the role the model takes when generating its next response.

  Placement: Appears after a user message, representing the AI's reply in the history.
  Example: "Bonjour le monde." or "Why don't scientists trust atoms? Because they make up everything!"

Hierarchy and Structure:

  [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user", "content": "Hi there!" },
    { "role": "assistant", "content": "Hello! How can I help you today?" },
    { "role": "user", "content": "What's the capital of France?" },
    { "role": "assistant", "content": "The capital of France is Paris." }
    // ... next user message would go here
]

In summary:
Roles: system (setup), user (human input), assistant (AI output), tool (external function results).
Hierarchy: Primarily chronological, dictating the flow of conversation. system has foundational influence,
user provides immediate direction, assistant provides context, and tool provides data. The alternating 
user/assistant structure is key to simulating dialogue.
