Async programming in Python is a concurrency model that allows a single thread to perform multiple 
tasks seemingly simultaneously by cooperatively switching between them. It's particularly useful for 
I/O-bound operations like network requests, file reading, and database queries, where the program 
spends a lot of time waiting for external resources.

Key Concepts:

  Coroutine: A special kind of function that can be suspended and resumed. In Python, coroutines are 
  typically defined using the async and await keywords.

  async Keyword: Used to define a coroutine function. This function can be paused (suspended) using 
  the await keyword and resumed later.

  await Keyword: Used inside a coroutine to suspend the execution of the function until the awaited 
  operation (another coroutine, task, or future) completes. It allows the event loop to switch to other ready-to-run coroutines.

  Event Loop: The heart of an async program. It's a single-threaded loop that manages and schedules the 
  execution of coroutines. The event loop monitors for I/O events and switches between coroutines when they're ready to run.

  Task: A wrapper around a coroutine that is managed by the event loop. Tasks are scheduled and executed 
  by the loop.

  Future: Represents the eventual result of an asynchronous operation. You can await a Future to get 
  its result when it becomes available.

How it Works:

 1. You define coroutines using async def.

 2. When a coroutine encounters an await statement, it pauses its execution and yields control back to 
    the event loop.

 3. The event loop then picks another ready-to-run coroutine and executes it.

 4. When the awaited operation (e.g., network request) completes, the event loop resumes the original 
    coroutine from where it left off.

When to Use Async:

 1) You have a large number of concurrent I/O-bound operations (e.g., making multiple API requests).

 2) You want to maximize the utilization of a single CPU core for I/O-bound tasks.

 3) You're using libraries that are specifically designed for asynchronous operation.

Async (asyncio):

    Single-threaded: Runs within a single thread. This eliminates the overhead of context switching between 
    threads, which can be significant. Also avoids problems with locks and race conditions that 
    multithreading has.

    I/O-bound: Best suited for I/O-bound tasks where the program spends most of its time waiting for 
    external resources (network, disk, etc.).

    Lower overhead: Typically more efficient than multithreading for I/O-bound tasks because of the reduced 
    overhead.

    Requires libraries: Requires libraries that are designed for asynchronous operation 
    (e.g., aiohttp, asyncpg).

    CPU-bound tasks aren't suitable because async still relies on a single thread

asyncio.run()
    asyncio.run() handles the entire lifecycle of the asyncio event loop for you. It automatically:
    Creates a new event loop.
    Runs the provided coroutine until it completes.
    Closes the event loop when the coroutine finishes. This is important for cleaning up resources and 
    preventing errors.
